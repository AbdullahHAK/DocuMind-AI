# Federal rules knowledge base

Plain-English summaries of US federal health-insurance rules, written for this
project from public government sources (healthcare.gov, CMS, U.S. Department of
Labor). Every file lists its primary source in `source_url`.

These summaries are educational, not legal advice. State laws can add more
protections, and some rules don't apply to every plan type (for example,
"grandfathered" plans and short-term plans). When the app quotes these files,
it labels them "What federal law says" so they're never confused with the
user's own policy.

Facts that change yearly (like the out-of-pocket maximum limit) are dated.
Last reviewed: October 2026.
